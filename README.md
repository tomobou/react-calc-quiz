## アプリの概要
React と Vite で構築された計算問題練習アプリです。答えは0〜10までの足し算を入力し、正解率と平均時間で評価を算出します。

## セットアップ手順
```bash
git clone https://github.com/tomobou/react-calc-quiz.git
cd react-calc-quiz
npm install
```

## 開発サーバ起動
```bash
npm start
```

## テスト実行方法
```bash
npm test
```

## ビルド・デプロイ
```bash
npm run build
npm run deploy
```
